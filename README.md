# Beecrowd 1066 - Pares, Ímpares, Positivos e Negativos

## Descrição

Este programa resolve o problema 1066 do Beecrowd, que consiste em ler 5 valores inteiros e contar quantos são pares, ímpares, positivos e negativos.

## Tecnologias utilizadas

- Java
- NetBeans
- Maven

## Entrada

O programa recebe 5 valores inteiros, que podem ser positivos, negativos ou iguais a zero.

## Saída

O programa deve imprimir a quantidade de valores pares, ímpares, positivos e negativos, cada informação em uma linha.
